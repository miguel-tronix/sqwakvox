Sqwakvox Project Report

1. Goal
Sqwakvox is a terminal user interface application for financial document analysis. The application reads financial documents and answers user questions about the data. The application uses Python and modular components for maintenance and expansion.

2. Scope
The application uses language models to analyze financial documents and extract data. A terminal user interface allows users to interact with the system.

3. Core Features
- Document Processing: The document module uses Docling to extract text and tables from PDF files.
- AI Agent: The agent harness uses Mozilla any-agent and LangChain to answer user questions about documents.
- Document Display: The display module shows extracted document text so users can read the source content.
- Data Extraction: The extraction module gets structured data from financial tables.
- Data Quality: The system uses Mozilla any-guardrail to validate queries and responses for compliance and safety.

4. Key Libraries
- any-agent: Manages language model agent workflows.
- textual: Provides the terminal user interface.
- docling: Parses documents and extracts table data.
- any-guardrail: Validates queries and responses for safety and compliance.

5. Testing
- Used pytest-asyncio for asynchronous test execution.
- Added type definitions for Jinja2 templates.
- Validated processing with sample file samples/banks.txt.
- Saved application screenshots in the screenshots directory.

6. Development Strategy
The design combines any-agent, LangChain, and document analysis modules into an agent harness. Textual provides the terminal interface for document display and agent chat. Mozilla any-guardrail inspects input queries and model outputs.

7. Error Analysis
The team fixed integration issues between any-agent and LangChain. The application writes debug logs to sqwakvox.log and chat logs to sqwakvoxchat.log.

8. Planned Improvements

- Support more language models.

- Add calculation tools.
- Create a web interface.
- Support multiple users.
- Support multiple open documents.
- Support multiple chat sessions.
